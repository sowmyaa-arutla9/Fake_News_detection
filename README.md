# 📰 Fake News Detection Website – *Veritas Analytics*

## 📌 Overview

**Veritas Analytics** is a web-based application designed to detect and flag potentially fake news articles using machine learning techniques. This platform empowers users to verify the credibility of online content in real-time, promoting digital literacy and combating misinformation.

---

## 🚀 Features

- ✅ Real-time fake news detection using a trained ML model  
- 📝 Input support for news headlines or full articles  
- 📊 Displays prediction results with confidence scores  
- 🌐 Clean, responsive frontend with HTML & CSS  
- 🔧 Python-based backend (Flask) for model inference  
- 📚 Trained on a labeled dataset of real and fake news articles

---

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript  
- **Backend**: Python, Flask  
- **Machine Learning**: Scikit-learn, Pandas, NumPy  
- **Model**: Logistic Regression / Decision Tree / Random Forest  
- **Dataset**: Fake and real news datasets (e.g., Kaggle)
